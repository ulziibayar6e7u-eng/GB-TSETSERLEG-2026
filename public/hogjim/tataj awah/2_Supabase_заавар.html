📌 Юуны тулд шаардлагатай вэ?

Танай өөрийн Supabase нь дараах зүйлсийг хадгална:

  • 👶 Хүүхдийн нэр, зураг, үнэлгээ
  • 📝 Хичээлийн төлөвлөгөө
  • 🎵 Дуу, хөгжимт хөдөлгөөн
  • 📊 Ирц, шалгуур бүх зүйл
✅ Зөвхөн та л харна. Өөр багш нар танай мэдээллийг харахгүй.

🔷 АЛХАМ 1: Supabase бүртгэл (3 мин)

  1. Хөтчид оч: supabase.com
  2. Баруун дээд "Start your project" ногоон товч дар
  3. Google Gmail-ээр нэвтэр (эсвэл шинэ бүртгэл)
  4. Хэрэв GitHub-аар нэвтрэх санал болгосон бол сонго — амархан

🔷 АЛХАМ 2: Шинэ Project үүсгэх (2 мин)

  1. Dashboard дээр "New project" ногоон товч дар
  2. Talбарууд бөглөх:
    • Name: hugjim-bagsh (эсвэл өөрийн нэр)
    • Database Password: хүчтэй нууц үг үүсгэх → заавал хадгал!
    • Region: Southeast Asia (Singapore)
  3. Ногоон "Create new project" дар
  4. ⏳ 2 минут хүлээ (Setting up project...)
  5. Dashboard гарч ирэхэд Status: Healthy харагдана ✅

🔷 АЛХАМ 3: URL болон API Key авах (1 мин)

  1. Зүүн доод ⚙️ Settings товч дар
  2. Зүүн талын жагсаалтаас "API" сонго
  3. Дараах 2 зүйлийг хуулж авна:
    • Project URL: https://xxxxx.supabase.co
    • anon / publishable key: sb_publishable_...
  4. Хоёуланг Notepad-т буулгаж хадгал
⚠️ service_role key бол илгээх ХЭРЭГГҮЙ! Зөвхөн publishable-ыг ашиглана.

🔷 АЛХАМ 4: Мэдээллийн сангийн бүтэц үүсгэх (3 мин)

  1. Өлзийбаяр багшаас ирсэн setup.sql файлыг Notepad-аар нээ
  2. Notepad-т Ctrl+A → Ctrl+C (бүгдийг хуулах)
  3. Supabase-т буц → зүүн талд SQL Editor товч дар
  4. "+ New query" дар
  5. Кодны цонхонд Ctrl+V буулгах
  6. Баруун доор RUN ногоон товч дар (эсвэл Ctrl+Enter)
  7. "Success. No rows returned" гарна ✅

🔷 АЛХАМ 5: URL, Key-ээ Өлзийбаяр багшид илгээх (1 мин)

Facebook Messenger дээр дараах маягтаар илгээ:

Багшаа Supabase бэлэн боллоо

URL: https://xxxxx.supabase.co
KEY: sb_publishable_xxxxxxxxxxxx

Өлзийбаяр багш танд config.js файлыг илгээнэ.

🔷 АЛХАМ 6: config.js-ыг GitHub-т upload

  1. Өлзийбаяраас ирсэн config.js-ыг татаж авна
  2. GitHub репод оч: github.com/танай-нэр/hugjim-...
  3. Хэрэв хуучин config.js байвал устга (🗑️)
  4. Add file ▾ → Upload files дар
  5. Шинэ config.js-ыг чирж хая
  6. Ногоон Commit changes дар
