📝 АЛХАМ 3: config.js файл үүсгэх

Хэрхэн үүсгэх вэ:

  1. Windows-т Notepad нээ
  2. Дараах 4 мөрийг хуулж буулгах:
window.SUPABASE_URL = "https://БАГШИЙН-URL.supabase.co";
window.SUPABASE_KEY = "sb_publishable_БАГШИЙН-KEY";
window.TEACHER_NAME = "Б.Багш нэр";
window.SCHOOL_NAME = "Цэцэрлэгийн нэр";
  1. Багшийн нэр, URL, KEY, цэцэрлэгийн нэрийг оруулах
  2. Ctrl + S дар
  3. File name: config.js бичих
  4. Save as type: All Files (*.*) сонго — заавал!
  5. Save дар

💡 Илүү хурдан арга:

Загвар config.js: _TEACHER_PACKAGE/CONFIG_ЗАГВАР.js

Загварыг хуулаад, дундах утгыг л сольж хадгална.

🚨 Түгээмэл асуудал шийдвэрлэх

Багш "Invalid path" гэж алдаа өгвөл?

Supabase URL-ын араас /rest/v1/ хойш хэсгийг устгах

Багш "syntax error near backtick" гэвэл?

setup.sql-т backtick ` тэмдэгт байгаа. Notepad-т Ctrl+H — Find ` Replace нь хоосон.

Багшийн сайт цагаан гарвал?

config.js алдаатай. Notepad-т нээж 4 мөрийг шалгах.

Багш GitHub Pages ажилахгүй бол?

Settings → Pages → Branch: main → Save (5 минут хүлээх)
