📌 Танилцуулга

Энэхүү систем нь 10 минутын дотор танай өөрийн серверт суурилуулагдана. Танд 2 үнэгүй бүртгэл шаардлагатай:

  • GitHub — системийн файлыг байршуулна
  • (Supabase бүртгэл шаардлагагүй — Улзийбаяр багшийн серверт хамтран холбогдоно)

🔷 АЛХАМ 1: GitHub бүртгэл үүсгэх (2 мин)

  1. Хөтөчид оч: github.com/signup
  2. Имэйл хаяг оруулах
  3. Нууц үг оруулах (санаж авах)
  4. Username сонгох (жишээ: bagsh-name)
  5. Имэйл-т ирсэн код баталгаажуулах
  6. Free төлбөрт сонго

🔷 АЛХАМ 2: Шинэ репозиторий үүсгэх (1 мин)

  1. GitHub-т нэвтэрсний дараа баруун дээд + → New repository дар
  2. Repository name: hugjim-bagsh (эсвэл ямар ч нэр)
  3. Public сонгосон эсэхийг шалга
  4. Доор "Create repository" ногоон товч дар

🔷 АЛХАМ 3: Систем файлуудыг upload хийх (3 мин)

  1. Улзийбаяр багшаас ирүүлсэн ZIP файлыг компьютерт задла (Extract)
  2. GitHub репод хэсэгт "uploading an existing file" линк дар
  3. Задалсан фолдер дотрох БҮХ файлыг сонгож (Ctrl+A) чирж хая:
    • index.html
    • plan.html
    • monthly.html
    • certificate.html
    • plan-data.js
    • болон бусад
  4. Доор ногоон "Commit changes" дар
⚠️ config.js файлыг үүсгээгүй — үүнийг Улзийбаяр багш танд тусад нь илгээнэ!

🔷 АЛХАМ 4: config.js файлыг upload хийх (1 мин)

  1. Улзийбаяр багшаас Messenger-аар ирсэн config.js файлыг татах
  2. GitHub репод буц
  3. "Add file ▾" → "Upload files" дар
  4. config.js-ыг чирж хая
  5. Ногоон "Commit changes" дар

🔷 АЛХАМ 5: GitHub Pages идэвхжүүлэх (1 мин)

  1. Дээд талд "Settings" товч дар
  2. Зүүн талын жагсаалтаас "Pages" сонго
  3. Branch хэсэгт main сонго
  4. Save дар
  5. 2-5 минут хүлээ
